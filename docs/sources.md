# Джерела даних для шкали

Статус перевірки: **за документацією** — з опису API чи сторінки, на живих даних ще не перевірено; **перевірено** — працює в коді.

> **Стан реалізації (v0.2.44).** Збирачі написані для: GOV.UK (перевірено), Німеччини, США, Канади, Австралії, Франції (лише текст), EASA CZIB, OpenSky, 13 новинних стрічок (`config/feeds.yaml`), GDELT (сплески і поради МЗС РФ/РБ), ЄЦБ (облігації, курси), Wikipedia (статус війни, перевірено). Кожне джерело перевіряється командою `tension-index probe <джерело>`. Не реалізовано: Ізраїль (немає відомого API), NOTAM (немає безкоштовного API для Європи), UCDP (потрібен токен).
Рівень довіри: 1 — первинні й офіційні, 2 — аналітика, 3 — структуровані бази, 4 — OSINT, тільки як тригер.

## Трекер війн

Для рядка «Статус війни» в боті.

| Джерело | Що дає | Доступ | Як використовуємо |
|---|---|---|---|
| [RULAC, Geneva Academy](https://www.rulac.org) | юридична класифікація: міжнародний і неміжнародний конфлікт, окупація | сайт, без API | **основа** ручного довідника `config/conflicts.yaml` (Молдова/Придністров'я, Кіпр — окупація) |
| [Wikipedia: List of ongoing armed conflicts](https://en.wikipedia.org/wiki/List_of_ongoing_armed_conflicts) | конфлікти за кількістю загиблих: 10 000+, 1 000–9 999, 100–999, менше 100 | MediaWiki API, без ключа | **щоденна автоматична звірка** (`war-check`); розбіжності йдуть адміну, бо список згадує й країни, які зачепило лише побічно (наприклад, падіння дрона) |
| [UCDP Candidate Events](https://ucdp.uu.se/apidocs/) | події з загиблими, щомісяця, із затримкою до місяця | безкоштовне API; з лютого 2026 потрібен токен (запит мейлом) | друге незалежне автоматичне джерело |
| [ACLED](https://acleddata.com/myacled-faqs) | події (бої, вибухи, протести) з геоприв'язкою | безкоштовний акаунт; обмеження залежать від категорії користувача, для публікації обов'язкова атрибуція | перевірити ліцензію для публічного сервісу |
| [CFR Global Conflict Tracker](https://cfr.org/global-conflict-tracker) | ~30 конфліктів зі статусом «погіршується / без змін» | сайт | ручна звірка |
| [Crisis Group CrisisWatch](https://www.crisisgroup.org/crisiswatch) | щомісяця: погіршення чи покращення, Conflict Risk Alert | сайт | блок Д, сигнал `crisiswatch:deteriorated` / `risk_alert` |

| 🇨🇦 Канада | [open.canada.ca](https://open.canada.ca/data/en/dataset/bef2ebb3-ca9a-485f-aaff-5dc36eb89426): `data.international.gc.ca/travel-voyage/index-updated.json` | JSON, відкрита ліцензія | за документацією |
| 🇦🇺 Австралія | [Smartraveller](https://www.smartraveller.gov.au/consular-services/resources) `/destinations-export` + RSS | JSON + RSS | за документацією |
| 🇫🇷 Франція | diplomatie.gouv.fr, Conseils aux voyageurs | HTML (кольорова карта: зелений / жовтий / помаранчевий / червоний) | відкритого API не знайдено, потрібен парсинг сторінок |
| 🇮🇱 Ізраїль | [NSC travel warnings](https://www.gov.il/en/departments/dynamiccollectors/travel-warnings-nsc) | HTML/JSON dynamic collector | за документацією; ⚠️ рівні для Європи зумовлені антисемітизмом і терором, тож вага через `reason` низька |

**Статус персоналу посольств** (найсильніший сигнал): формулювання «authorized departure», «ordered departure», «limited consular services», «embassy suspended operations» у текстах США, Великої Британії, Канади, Австралії. Їх виявляє класифікатор.

|---|---|---|

## В. Внутрішні заходи країни

Мобілізація, надзвичайний стан, перевірка укриттів, закриття кордонів, EU-Alert. Єдиного API немає. Джерела: урядові сайти й новини рівня 1, класифікація через Claude.

## Відкриті питання

1. Ліцензія ACLED для публічного сервісу.
2. Токен UCDP: написати мейнтейнеру API.
3. Чи блокують сайти МЗС РФ/РБ і diplomatie.gouv.fr запити з нашого сервера.
4. Безкоштовне джерело NOTAM для Європи; поки що CZIB і OpenSky.
